1 Edge Impulse project

Create a project at studio.edgeimpulse.com, then copy its API key from Dashboard → Keys. The key is only sent to this board, which talks to Edge Impulse for you.

2 Record gestures

    Continuous motion recognition: repeat the gesture over and over for the whole recording (10 s ≈ 8–10 gestures). Record idle too: holding the wheel and steering normally, so steering never triggers a gesture.

    3 Train & deploy

    then deploy it one of these two ways:

    A · Motion detection brick recommended

    Runs on the Linux side in App Lab's Motion detection brick. No sketch rebuild; swap models from App Lab.

    1. Click Train the model above.
    2. In Edge Impulse Studio: Deployment → target Arduino UNO Q → Build, then Go to Arduino. Open Deployment ↗
    3. In Arduino App Lab open Ardu Kart, click the Motion detection brick → AI models → Download your model.
    4. Brick Configuration → select your model → Save, then Run the app.

    B · Model on the MCU

    Built as an Arduino library, installed into the sketch from here and run on the STM32U585. Needs an app restart (sketch recompile).

    1. Train
    2. Build library
    3. Download
    4. Install
    5. Ready
